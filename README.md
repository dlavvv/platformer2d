# 🏔 Wizard's Tail
This project is a **_2D platformer game_** made in Unity, with C#.  
It follows the journey of the Wizard finding his way back to the his old castle, after being away from it for 100 years and the obstacles he has to face in order to get there. 
So, the player is on the Wizard's "tail"😉.

Structurally, the game has **_3 levels_** varying in difficulty, design and appearence, with different types of enemies and obstacles.  

The game also has an educational side, providing a creative way for the player to respawn in case he runs out of health - a collection of questions about topics like history, science, geography and culture. A random question will pop-up and the player has to answer correctly if he wants to be respawned.

## About the Functionalities
- Arrow keys and Space key - for character movement
- Left click - for the attack ability
- Traps and obstacles that deplete the Wizard's health (3 hearts, leading to Game Over when gone)
- Checkpoints for respawning
- Pop-up window with 1 question to answer for respawning
- Pause menu options to Restart the game, go to Main Menu or adjust the settings
- Animations for all the Wizard's states
- Sound effects for different events
